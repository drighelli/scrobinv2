# Robin Version 2 to Single-Cell-RNASeq

This repository is a resource to demonstrate how the robin (Robustness in Network) 
package (>=v.2) can be applied to single cell data, in order to answer the following question:

**How well do clusters approximate cell subtypes?**

![](https://user-images.githubusercontent.com/44773104/144223969-d1de527a-15a4-4914-9de9-85a053e68842.png)

By exploring the Articles present at this website [https://drighelli.github.io/scrobinv2/](https://drighelli.github.io/scrobinv2/),
we show how the made improvements to the robin package helps to speed up the computations in order to 
apply the implemented models to high-dimentional single cell data.

Robin gives the possibility to choose the community detection algorithm that 
**better** fits your single cell network and to investigate if the communities 
that it gives are **statistically significant**.

Package is at: [https://cran.r-project.org/package=robin](https://cran.r-project.org/package=robin)
